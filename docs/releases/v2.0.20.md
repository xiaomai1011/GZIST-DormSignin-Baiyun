# 2.0.20 稳定性更新

## 首先说明：二次验证问题尚未正式解决

本版本没有绕过或正式解决学校的手机／其他二次验证。学校要求验证时，仍需本人在官方窗口完成。常驻浏览器、保留 Cookie、记住密码均不构成长期免验证保证。

两晚成功可能与学校近期取消、放宽或暂时未触发二次验证有关。这是尚未证实的原因推测：没有校方确认，也没有同条件版本对照，不能宣布学校已经全面取消二次验证，更不能将其宣传为本版本实现了免验证。

## 相较公开 v2.0.2 的改进范围

- 完善登录状态、表单读取失败和认证跳转的判断与脱敏诊断。
- 识别官方二次验证页，显示对应窗口，由本人完成后接续同一任务。
- 增加按账号隔离的常驻浏览器及受控标签页复用，完善生命周期与失败清理。
- 修复隐藏状态下的输入问题，约束窗口控制范围，避免批量显示辅助窗口。
- 严格选择业务签到按钮，传递动作错误，结果不明时停止重复尝试。
- 新任务从稳定业务入口开始，不将遗留的验证页面直接视为有效认证流程。
- 保留 MyGO!!!!!／长崎爽世主题和本地用户数据。

业务等待超时后的单次会话恢复已存在于 v2.0.2，不重复列为新增功能，也不将两晚成功归因于某一项未经对照验证的改动。
