# GZIST DormSignin v2.0.2

Windows x64「验证登录」诊断与结果展示版本，修复构建标识：`verify-diag-r6`。

本版**不改签到主流程**（自动登录、定位注入、安全闸门、点击与调度规则同 v2.0.1），集中改「验证登录」这一条独立链路：结果怎么显示、怎么拿到更多可信证据、出问题时怎么留痕。

## 「验证登录」的结果改为结构化四态

| 显示 | 触发 |
|---|---|
| **✓ 绿色框**（账号密码验证通过） | 认证服务签发了新的可信票据；文案明确写出「本次仅验证登录，未执行签到，也未自动保存」 |
| **ⓘ 蓝色信息框** | 未识别的业务码、响应读取失败／超时、**网络或浏览器连接失败（监听/导航/请求）**——即「没取得可信结论」这一类 |
| **顶部红条** | 凭据被明确拒绝、账号被锁定／停用 |
| 普通文字 | 进行中、已取消、输入已修改（旧结果作废） |

- 展示**只由结构化字段（是否成功 / 类别 / 内部原因码）决定，不匹配文案**：消息里恰好出现「密码错误」四个字也不会把未识别的结果染成红色。
- 蓝色框与绿色框在浅色／深色主题下各自配色，正文与底色的对比度按 WCAG ≥ 4.5 校验。
- 取消、输入变更、迟到结果一律不留框；浏览器清理未确认时仍走红色阻断条。

## 未识别业务码：有界的页面提示辅助分类

- 仅在**收到可信、且与本次提交关联的未识别业务码响应**之后，才会在既有总预算内**最多 2 秒**看一眼登录页自身的错误提示。
- 约束（全部有测试守着）：只读登录页**固定的错误区域**（可见性过滤，不扫正文／帮助文本）；页面必须是**可信的认证文档**；提示必须是**本次提交后新出现或变化**的句子（提交前先取快照，旧弹窗不可复用）；**不点击、不刷新验证码、不重载、不重复提交**；取消与总超时**优先于**这次观察；页面文字只在内存里分类，不写日志、不进界面。
- 采信范围（均为认证前端里的固定文案，据本机保存的公开前端代码逐条核对）：`用户名或密码错误。`／`密码错误` → 凭据拒绝；`账号锁定至:…`／`账号被停用…`／`验证码错误` → 锁定／停用、验证码；`密码已连续错误【n】次…`（整句匹配，不足或多余文字都不认）→ 凭据拒绝或锁定。
- **学校页面只提示「登录失败」这类泛化文案时，仍然显示蓝色未知框**，绝不判成密码错误；看不到、读不到、来源不可信、含义不明，同样保持蓝色未知。

## 验证登录诊断（一行，默认开）

每次「验证登录」在日志里写**一行**脱敏摘要，可用 `DORMSIGN_VERIFY_DIAG=0` 关闭：

```
验证诊断: stage=… failed_stage=… reason=… error_class=… cleanup=… release=… shutdown=… leftover=… code=… http=… bytes=… trusted=… cached=… req=… prompt=… elapsed=…s
```

- 只含固定枚举、有界数字和请求 id 的 8 位哈希；**不含**账号、密码、Cookie、票据、完整 URL、响应体或页面文字。
- `failed_stage`／`reason`／`error_class` 能直接指出失败发生在哪一步（启动、打开登录页、监听、导航、点击、等待响应、分类、清理）与错误的粗略类别。
- `release`／`shutdown`／`leftover` 记录响应捕获的释放与关闭流程是否干净。
- `prompt=` 是本次新增的页面提示观察结果：`snapshot_failed`（提交前快照没取到，页面路径整轮禁用）／`no_new_sentence`（没看到可用提示）／`credential`·`locked`·`captcha`·`password_counter`·`password_lock`（页面确认了具体原因）／`generic`（页面只说「没通过」）／`interrupted`（被取消或超时打断）。

## 响应捕获与关闭流程（本版包含的修复）

- 用 Fetch 拦截在**响应阶段**读取认证响应正文，修复**本地回环已复现**的「客户端拿到响应后立即重定向导致正文读取丢失」；**真实故障是否同因仍待确认**。
- 正文读取失败细分 4 类，关闭流程改为一次性 seal ＋ 有界清扫，释放结果与关闭状态单独记录。

## 边界（请如实看待）

- **未知业务码的真实语义仍未确定。** 本版补齐的是「结构化展示 ＋ 页面辅助证据 ＋ 可诊断性」，**不能据此认为真实环境中的错误识别问题已经解决**。
- **未与真实统一认证联调。** 验证路径的验证深度是：离线全量单测 ＋ 本地回环真 Edge 集成用例（本地起页面，不访问学校）。
- 签到主流程、调度与账本规则同 v2.0.1；本版不改学校接口、不新增任何网络请求，也不采集页面正文。
