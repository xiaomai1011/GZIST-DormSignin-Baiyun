# GZIST DormSignin v2.0.1

Windows x64 调度修复版本，修复构建标识：`daily-ledger-20261011-r3`。

## 修复目标

- 修复当天签到成功后仍在后续定时时间点重复运行的问题。
- 将定时时间点去重与当天成功记录分开，不再使用 `23:59` 哨兵冒充成功状态。
- 在随机延时前认领时间点，延时后重新核验日期、配置、账号及成功状态。
- 将当天已确认成功与最近一次尝试结果分开，后续失败不再把当天成功改成失败。
- 使用按账号摘要和本地日期关联的成功记录，支持重启后恢复；新记录不保存明文学号、密码、Cookie或认证票据。
- 签到使用按账号隔离的浏览器数据子目录，避免换账号后将旧登录会话的成功记给新账号。保留原浏览器数据，不复制旧会话；首次使用新版时会重新登录。
- 延时后同时核验实际经过时间与本地时钟，拒绝时钟回拨或过期的时间点。

## 边界

本次不改变学校业务接口、页面等待时限或签到提交逻辑，不包含纯 HTTP 签到功能。业务页面偶发只加载外壳的问题仍需独立诊断。

不会根据旧日志自动推断当前账号已签到。新版本首次使用时，需要通过正常流程确认成功，之后才能建立新的当天成功记录。

## 验证与下载

- 本地全量单元测试（`DORMSIGN_EDGE_TEST=0`）、`go vet ./...` 与差异格式检查通过；未启动真实浏览器或访问学校进行回归验证。
- 发布资产为 Windows x64 绿色 EXE、Setup 安装包和 `SHA256SUMS`，不包含用户配置、日志或浏览器数据。
- 安装或切换前应先从托盘退出旧程序（仅关闭窗口不够）；不要同时运行多个副本。此版本的测试不代替学校侧真实签到验证。
- 成功状态写盘失败时，仅在当前进程内保留自动重试抑制；状态文件损坏或无法读取时，无法恢复先前记录，并会写入日志提示。
