# GZIST DormSignin v2.0.0

这是重建后的公开仓库首发版本，使用当前已修复代码并从干净 Git 历史开始。版本号按维护者要求重新从 2.0.0 起步，不是回退到此前旧仓库的 2.0.0 代码，也不是给旧安装包改名。

## 平台与下载

需要 Windows 10 或更新版本（x64）及 Microsoft Edge。

- `GZIST-DormSignin-v2.0.0.exe`：绿色单文件。
- `GZIST-DormSignin-v2.0.0-windows-x64-setup.exe`：安装包。
- `SHA256SUMS`：两个文件的 SHA-256 校验值。

## 包含的修复

- 创建 Edge 时原子加入 Windows Job Object，关闭或程序异常退出时回收本程序浏览器进程树，不清理用户正常浏览器。
- 专用浏览器目录互斥；手动与定时任务防止并发执行。
- 修复 CDP 页面文本读取，保留 120 秒业务页面等待预算，避免过早刷新与提前退出。
- 按实际页面域名检查安全条件，修复登录表单宽限、定位权限及提交前晚归线复核。
- 提交后观察结果 30 秒，处理延迟验证码，不盲目重复提交。
- 保留运行版本与路径诊断，以及仅访问本地空白页的浏览器自检入口。

## 验证说明

修复阶段已完成测试与本地 Edge 生命周期验证；用户已反馈实机运行成功，README 收录已遮挡学号和坐标的成功截图。该截图不单独证明定时自动触发已经验证。本次仅重新构建和发布，不重复运行应用或触发学校登录、签到。

## 更换版本

旧私有版本的用户无需仅因版本号重新编号而更换正在使用的程序。需要更换时先自行从托盘退出旧程序，保留设置及专用浏览器数据；绿色版保持原文件名和路径，避免开机自启失效。未配置代码签名证书，请核对来源及 SHA-256。

请仅在本人实际处于允许考勤范围时使用，遵守学校规定。
